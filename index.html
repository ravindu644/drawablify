SVG to Android VectorDrawable

Converts SVG, PNG, JPEG and GIF files to VectorDrawable XML. Files are converted in your browser and never uploaded.

Paste SVG markup

Supported: paths, basic shapes, groups, transforms, CSS styles, <use>, clip paths, and linear and radial gradients. Gradients need API 24 or newer.

VectorDrawable has no text, masks, filters, patterns, markers or dashed strokes. When an SVG uses them, the result lists a warning.
